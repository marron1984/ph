# 令和8年熊本地震 緊急支援募金サイト

2026年7月28日に熊本県熊本地方で発生したマグニチュード7.1・最大震度7の地震
（令和8年熊本地震）に対する**緊急人道支援募金サイト**です。**国際 P-LP 財団
（International Peace-Loving People Foundation / [iplpf.org](https://iplpf.org/)）**
が運営主体となります。

## 概要

- 被害状況・最新情報の紹介（出典リンクつき）
- ご寄付の使い道の説明
- 金額選択・カスタム金額に対応した寄付フォーム（単発／毎月）
- 運営団体（IPLPF）の紹介
- レスポンシブ対応（スマートフォン・タブレット・PC）
- 依存ライブラリなしの静的サイト（HTML / CSS / Vanilla JS）

## 義援金の受付方法（銀行振込のみ）

義援金の受付は **銀行振込のみ** です。振込先はサイトの寄付セクションに掲載しています。

| 項目 | 内容 |
|------|------|
| 銀行名 | GMOあおぞらネット銀行 |
| 支店名 | 法人営業部 |
| 口座種別 | 普通 |
| 口座番号 | 1576120 |
| 口座名義 | 一般財団法人　国際ピースラビングピープル財団義援金受付 |

- 口座情報の記載箇所は `index.html` の `.method-panel[data-method="bank"]` ブロックです
- 各項目には「コピー」ボタンが付き、ワンタップでコピーできます（`js/ui.js`）
- フォームはお申し込み内容の受付のみで、オンライン決済は行いません

### 振込番号による照合

お名前とメールアドレスを入力すると、照合用の **6桁の振込番号** が自動発行されます。
寄付者には「振込人名義の先頭に振込番号を付ける」（例：`123456 ヤマダ タロウ`）よう
案内し、入金と申込者を突き合わせられるようにしています。

- 番号はメールアドレスから決定的に生成（`js/main.js` の `transferCode()`）。
  同じメールアドレスなら常に同じ番号になるため、財団側でも同じ計算で再現できます
- 現在は**ブラウザ内のみで完結**し、申込内容はサーバーに送信されません。
  実運用で申込一覧と入金を管理する場合は、フォーム送信先（サーバー／
  フォームサービス）の追加を推奨します

### 活動報告ページ（report.html）

ご寄付いただいた方のお名前（ご芳名）を掲載する活動報告ページです。

- 活動報告のタイムライン（受付開始のお知らせを初回掲載）
- ご支援者一覧：この端末の受付記録から **匿名希望を除き受付順** に掲載
  （`js/report.js`）。実運用では入金確認済みの名簿への差し替えを推奨
- 「匿名で寄付する」を選んだ方は掲載されない旨と、掲載修正の連絡先を明記

### 管理画面（admin.html）

`admin.html` で、発行済みの振込番号と申込者を確認できます。

- **受付リスト** … フォームで申込された記録（受付日時・振込番号・お名前・
  メール・金額・種別）を一覧表示。検索・1件削除・全件削除・CSVエクスポート対応
- **照合ツール** … メールアドレス1件、または「お名前,メールアドレス」の
  複数行貼り付けから振込番号を再計算（結果のCSV保存可）

注意点:

- 受付リストは `localStorage` 保存のため、**申込者が操作した端末ごと**の記録です。
  全端末の申込を一元管理するにはサーバー側の受け口が必要です
- `admin.html` に認証はありません。公開サーバーに設置する場合は
  Basic認証などのアクセス制限を必ずかけてください（`noindex` は設定済み）
