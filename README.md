# ミンダナオ島地震 緊急支援募金サイト

フィリピン・ミンダナオ島で2026年6月8日に発生したマグニチュード8.2の地震に対する
**緊急人道支援募金サイト**です。**国際 P-LP 財団
（International Peace-Loving People Foundation / [iplpf.org](https://iplpf.org/)）**
が運営主体となります。

## 概要

- 被害状況の紹介（地図・現地写真）
- ご寄付の使い道の説明
- 金額選択・カスタム金額に対応した寄付フォーム（単発／毎月）
- 運営団体（IPLPF）の紹介
- レスポンシブ対応（スマートフォン・タブレット・PC）
- 依存ライブラリなしの静的サイト（HTML / CSS / Vanilla JS）

## ファイル構成

## 寄付の受け取り方法

寄付フォームの「お支払い方法」で以下を選べます。**値はすべて仮（サンプル）** で、
正式な情報に差し替えて運用します。差し替え箇所は `index.html` の各
`.method-panel`（`data-method="..."`）ブロックです。

| 方法 | `data-method` | 差し替える内容 | 実稼働に必要なもの |
|------|---------------|----------------|--------------------|
| クレジットカード | `card` | ― | Stripe / KOMOJU / Square 等の連携 |
| QRコード決済 | `qr` | QR画像（PayPay / LINE Pay 等） | 各サービスで発行したQR |
| コンビニ・キャリア決済 | `konbini` | 対応ブランド表記 | 決済代行（Stripe / KOMOJU 等） |
| 銀行振込 | `bank` | 銀行名・支店・種別・番号・名義・カナ | 振込先口座 |
| ゆうちょ振替 | `yucho` | 記号・番号・加入者名 | ゆうちょ振替口座 |
| 仮想通貨（暗号資産） | `crypto` | BTC / ETH / USDT アドレス | ウォレット／取引所口座、会計・税務・法令の確認 |
| 寄付プラットフォーム | `platform` | Congrant / Syncable 等のURL | 各プラットフォームのキャンペーンページ |

### オンライン決済の有効化

カード・QR・コンビニ・キャリア決済を実際に稼働させるには、決済事業者との
連携が必要です（**Stripe** はカード／Apple Pay／コンビニ、**KOMOJU**／**fincode**
は国内のコンビニ・キャリア決済に強い）。`js/main.js` の送信処理
（`form.addEventListener("submit", ...)`）を、決済プロバイダのリダイレクトまたは
API 呼び出しに置き換えてください。

### 仮想通貨の注意点

`crypto` パネルのアドレスは仮です。受領後の換金方針、会計・税務処理、
資金決済法など関連法令の取扱いを財団側で別途ご確認ください。
